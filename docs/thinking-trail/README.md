# Thinking Trail

重要设计讨论的对话留痕。文档讲"是什么"，Thinking Trail 讲"**为什么当时这样想**"。

格式参考 Orbit 桌面端的 `docs/thinking-trail/` 做法：

```
YYYY-MM-DD-<topic>/
├── conversation.md       # 原始对话（不压缩）
├── key-pivots.md         # 关键认知跃迁点
├── decisions-traced.md   # 每个决策的来龙去脉
└── README.md             # 导读
```
