# Archive

过时文档的归档。**不删除是为了保留项目思考的轨迹**。

## 归档规则

- 被 ADR superseded 的旧方案 → 搬来这里
- 被大改版的老 plan（status: abandoned）→ 搬来这里
- 本文件夹的内容**仅供参考**，不是当前设计

## 命名

保留原文件名 + 前缀归档日期：`YYYY-MM-DD-<original-name>.md`

## 与 decisions/ 的区别

- `decisions/` 存的是**决策本身**（ADR，即使 deprecated 也留在原位置）
- `archive/` 存的是**被决策淘汰的文档**
